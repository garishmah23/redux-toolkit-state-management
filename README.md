# 🚀 Redux Toolkit State Management

A React application demonstrating centralized state management using **Redux Toolkit**. This project allows users to create, manage, and delete social media posts while maintaining a centralized global state.

---

### Aim
To implement centralized state management using Redux Toolkit for efficiently managing application data such as posts and platforms.

### Objective
- Understand Redux Toolkit architecture
- Implement centralized global state management
- Create and configure Redux Store
- Manage application state using Redux Slices
- Perform CRUD operations using Redux actions
- Improve scalability and maintainability

---

## ✨ Features

- 📝 Create social media posts
- 🌐 Select publishing platform
- 🗑 Delete posts
- ⚡ Centralized global state management
- 📦 Redux Toolkit Store
- 🔄 React Redux integration
- 🎨 Clean and responsive UI

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/redux-toolkit-state-management.git
```

### Navigate to Project

```bash
cd redux-toolkit-state-management
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```
